2D rig parts / Части персонажа

Advanced setup: provide separate transparent image files for body parts and connect them to bones. A single full-body image is not automatically separated. Use HTTPS image URLs; local blob URLs are temporary and will not survive a page reload. For joint rotation, set both pivotX and pivotY on a bone using normalized scene coordinates (the same coordinate space as part x/y); omit both to keep legacy rotation-only behavior.










Presets are generated from recognized bone IDs. Rename bones to root, leftArm, rightArm, leftLeg, rightLeg, or head for the best mapping.




Drag the slider to inspect any pose without waiting for playback. Reset returns to the scene's animation clock.


Create at least a start frame at 0 and an end frame at 1. Values are normalized offsets; rotation is in radians.


Facial rig editor / Редактор лица

Add separate transparent PNG/WebP images for eyes, eyelids, brows and mouth. Coordinates are normalized to the scene canvas (0–1); rotation is entered in degrees. This editor positions supplied images; it does not cut parts from a full-face image.


























Add a body rig with a head bone, then assign separate facial images. / Добавь скелет с костью головы и отдельные изображения лица.
